**What is the cybersecurity landscape, and why does it matter?**

```
The cybersecurity landscape is the full picture of who is building and protecting digital infrastructure, who is attacking it, and how attackers and defenders are constantly adapting to each other. Understanding this landscape matters because cybersecurity professionals need to be prepared to identify threats and vulnerabilities, assess risk, and respond to incidents, and keep up with changes in the systems around them.
```

**How do hardware, OS, and software layers interact?**

```
Hardware provides the foundational components that the operating system and software are built upon. The four main hardware components of a computer are the CPU, RAM, storage, and motherboard. The motherboard attaches them all together, with circuits and ports that allow them to communicate and function as part of a whole instead of disparate parts. The CPU is the "brain," though not conscious, that is responsible for executing instructions and doing the work that is required. RAM serves as the active workspace, while storage holds programs, files, and data long-term.

The operating system sits on top of the hardware layer and manages those resources so the computer can actually be used. It allocates CPU time, manages RAM and storage, provides the user interface, and starts and manages programs as processes. Software sits on top of the operating system and depends on the OS to access the hardware resources it needs. When a program is opened, the OS allocates and coordinates the hardware resources the software needs so the program can run.
```

**One term I want to remember from this week, and why:** Attack surface

```
The attack surface of a person or organization grows with every new connection that they establish in the digital realm. New connected devices automatically mean new entry points for possible threat actors, and that means there will always be more to understand, configure, monitor, and protect.
```
